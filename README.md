# تطبيق إيقاع (Iqaa App) - Android Studio Project

مشروع أندرويد متكامل لتطبيق "إيقاع" لتنظيم دورات النوم، تقنية البومودورو، ومتابعة شرب الماء.

## كيفية البناء واستخراج الـ APK:

### الطريقة الأولى: عبر Android Studio
1. قم بفك ضغط هذا الملف.
2. افتح برنامج **Android Studio** واختر **Open**.
3. اختر مجلد المشروع `IqaaProject`.
4. انتظر اكتمال مزامنة الـ Gradle.
5. من الشريط العلوي، اختر:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`.
6. سيظهر لك إشعار في الأسفل برابط مجلد الـ APK (`app-debug.apk`).

### الطريقة الثانية: بناء تلقائي عبر GitHub Actions (بدون تثبيت أي برامج)
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع ملفات هذا المجلد بالكامل إلى المستودع.
3. ستجد ملف العمل `.github/workflows/build-apk.yml` مجهزاً بالفعل.
4. توجه إلى تبويب **Actions** في صفحة المستودع.
5. ستجد عملية البناء قد بدأت تلقائياً، وبعد دقيقة ستجد ملف `Iqaa-App-Debug-APK` جاهزاً للتنزيل المباشر.
